# Si_RTS_AI

A MelonLoader mod for the Silica dedicated server that replaces or augments the
game's built-in commander AI: an economy planner (opener, blueprint, beam
planner, shrimp assignment), a scout star, a military layer (objectives,
forces, production, spires) and the observability that everything above was
tuned against. Server-side only; clients need nothing.

Version 0.94.0. Game Beta 0.9.47.

## Layout

```
Si_RTS_AI/            the mod (C#, netstandard2.1, Mono — see include/)
  Si_RTS_AI.cs        MelonMod lifecycle + the master switch, nothing else
  Config/             json configuration: Paths, RtsaiConfig (reader),
                      ConfigStore (active config + state.json), ModSwitches
  Core/               TeamTick (the 1 Hz per-team dispatcher), RoundLifecycle,
                      RoundLog, FrameBudget, RecentModWork
  Chat/               /rtsai command and its numbered menu
  Perception/         what the game is doing: EventLog, CommanderLog, maps,
                      intel samplers, telemetry server, perf probes
  Planning/           the economy: OpenerPlanner, Blueprint, EcoPlanner, ScoutPlanner...
  Mil/                military v3: Intel, Fields, Objectives, Forces, ProductionV3, SpirePlanner
  Faction/            per-faction takeovers (AlienConstruction, HumanConstruction)
                      and the order gates (VanillaOrderGate, SuppressCombat, ...)
  TestHarness/        the headless soak driver (testMode)
configs/presets/      the shipped configurations (generated by tools/make_presets.py)
configs/KEYS.md       every configuration key, with its default
configs/<name>/       pre-0.94 config sets, kept for history
docs/                 ARCHITECTURE, DESIGN, military/, handover/, experiments/
tools/                build/deploy/analysis scripts (release.py, loop/, make_presets.py)
analysis/ eco_sim/ mil_sim/ site/   measurement and modelling side projects
```

## Build and deploy

```
cd Si_RTS_AI && dotnet build -c Release      # -> bin/Release/Si_RTS_AI.dll
```

Copy the DLL to `<server>\Mods\` (the dedicated server only; the game client
does not use it). The server holds the DLL open while it runs, so copy between
rounds. `python tools/release.py` tags, builds, archives and deploys in one go
and can jump back to any archived version.

## Configuration

Everything the mod reads lives in **`<server>\UserData\RTSAI\`**:

```
UserData/RTSAI/
  configs/*.json          one file per configuration; exactly one is active
  state.json              written by the mod: active config + chat overrides
  rtsai_units.json        production prior
  mil_doctrine.json       fitted commitment bands and unit values
  commander_compositions.csv
UserData/RTSA/            round logs, layer replays, benchmark rows (unchanged)
```

Nothing is in MelonPreferences.cfg any more (MelonLoader rewrites that file
from memory on shutdown, which silently reverted every edit made while the
server ran). The active config is re-read at every map load, so editing it
takes effect on the next round with the server up. The first start on an old
layout imports `UserData/rtsai.json` plus the three old preference sections into
`configs/migrated.json` and activates it, so behaviour does not change until a
different config is chosen.

Presets (see `configs/README.md`): `public-play`, `coop-eco`, `coop-eco-scout`,
`coop-ai-commander`, `headless-alien-only`, `headless-all-factions`,
`headless-eco-only`, `off`. Every key is documented in `configs/KEYS.md`.

Precedence for a switch: chat override (state.json) > active config > built-in
default.

## In game

```
/rtsai                      admins: the menu · others: status
/rtsai on | off | auto      master switch (off = the mod does nothing at all)
/rtsai config [name]        list / activate a configuration
/rtsai log [cmd|round] on|off|auto   commander-action logging / round log file
/rtsai enable alien|sol|centauri on|off     per-faction switch for this round
/rtsai status · /rtsai mil · /rtsai reload · /rtsai override [team] on|off
```

The menu is numbered like Si_UnitBalance's `!b`: `/1`..`/20` pick, `/0` exits,
`/back` goes up. Both mods own those shortcuts; this mod forwards them to
UnitBalance whenever the caller is not inside the RTS AI menu.

**The master switch is total.** With `enabled: false` (or `/rtsai off`) no
Harmony prefix runs its body, no tick does work, no round log or jsonl is
written, the telemetry listener is down, and `timeScale` / `serverFpsCap` are
handed back to the game. Before 0.94 "off" only meant the alien faction flag.

## Reading a round

`UserData/RTSA/round-<stamp>-<map>.log` is the per-round text log (orders,
spawns, [CMD] construction requests, cash samples, planner decisions, the round
summary at the end); the `.melon.log` beside it is a copy of the console log
taken at round end. `tools/loop/` turns a batch of rounds into
`analysis/loop/report.md`.
